# After Effects adapter

Esta pasta contém a camada específica do SDK:

- `EffectMain` e `PluginDataEntryFunction2`;
- registro PiPL;
- parâmetros do Effect Controls;
- conversão de `PF_EffectWorld` para o buffer do core;
- SmartFX e suporte a 8/16/32 bpc.

O projeto utiliza os headers e as ferramentas de resource compiler do SDK oficial indicado por `AE_SDK_ROOT`.
