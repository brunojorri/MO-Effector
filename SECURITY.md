# Segurança

O instalador modifica o `PresetEffects.xml` porque o After Effects exige o registro do pseudo-effect. Antes de qualquer alteração, uma cópia com timestamp é criada ao lado do arquivo original.

O script baixa exclusivamente o repositório público `brunojorri/mo-effector`, escreve no diretório CEP específico `com.docato.moeffector` e não coleta dados.

Para relatar uma vulnerabilidade, abra uma issue sem publicar informações sensíveis ou entre em contato com o autor pelo perfil indicado no README.
